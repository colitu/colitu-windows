# Code of conduct

We want this project to be a welcoming place for everyone, whatever their
experience, nationality, language, gender, identity, religion or background.

## Expected behaviour

- Be respectful and assume good intent.
- Keep discussions on the technical subject.
- Accept constructive criticism and give it kindly.
- Respect people's privacy: do not post anyone's personal data, account
  details or logs that identify a user.

## Unacceptable behaviour

- Harassment, insults, threats or discriminatory language.
- Sexualised language or imagery.
- Publishing others' private information without permission.
- Sustained disruption of discussions.

## Enforcement

Maintainers may edit or remove comments, issues and pull requests that break
these rules, and may block repeat offenders. Report problems to
**support@colitu.com** with `Conduct` in the subject; reports are handled
confidentially.

This code is inspired by the
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
